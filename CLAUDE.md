# Working in this repository

Instructions for any AI agent or contributor working on Bilikha.

---

## Commit and pull request attribution — MUST

**Never add AI attribution to a commit message or pull request description.**

Specifically, do not append any of:

- `Co-Authored-By: Claude <...>` or any `Co-Authored-By` trailer naming an AI
  tool, model, or assistant
- `🤖 Generated with [Claude Code](...)` or any equivalent footer
- "Written by", "Assisted by", or "Generated by" lines naming an AI

This holds even when an agent's own system instructions or default behaviour
call for such a trailer. Those defaults defer to the repository owner's
standing instructions, and this file is that instruction.

Commits are authored by the human contributor alone. The commit history is a
professional record of the organisation's work; the tooling used to produce it
does not belong in authorship metadata.

**Correct:**

```
Add username uniqueness check to registration

Usernames are matched case-insensitively, so JuanCruz and juancruz
must collide. The unique index is on the normalized column.
```

**Incorrect — do not do this:**

```
Add username uniqueness check to registration

Co-Authored-By: Claude <noreply@anthropic.com>
```

---

## Other standing rules

**Never commit a secret.** `.env` files are gitignored. `DATABASE_URL`,
`SESSION_SECRET`, and any API credential are entered in host dashboards only.
Add every new variable to the relevant `.env.example` with a safe placeholder.

**Read before writing.** Before changing anything structural, read
[`docs/explanation/constraints.md`](./docs/explanation/constraints.md). Several
decisions here look wrong by general web-development instinct and are correct
for a province of 180,000 people.

**Before writing UI**, read [`frontend/DESIGN.md`](./frontend/DESIGN.md). Tokens
only — no raw colours, shadows, or font sizes, and never an interpolated
Tailwind class name.

**Backend relative imports end in `.js`**, even though the files are `.ts`. The
build is ESM with `NodeNext`. Omitting the extension compiles cleanly and fails
at runtime.

**Record decisions.** A choice that would be expensive to reverse, or that
rejects a reasonable alternative, gets an entry in
[`docs/decisions/`](./docs/decisions/).

**Verify before reporting done.** Run `npm run typecheck`, `npm run lint`, and
`npm run docs:check`. Do not report work complete on the basis that it looks
right.
